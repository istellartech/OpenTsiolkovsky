# 物理モデルと数値計算（Rust版）

Rust版シミュレータ（`src/`）が解いている式と、そのモデル・数値計算法・仮定をまとめます。各項目の C++ 版との違いは最後の節にあります。

## 座標系

| 座標系 | 定義 |
| --- | --- |
| ECI | 地球中心慣性系。t = 0 で ECEF と一致し、Z 軸まわりに回らない座標系（歳差・章動は無視） |
| ECEF | 地球固定系。ECI から角速度 ω = 7.2921159e-5 rad/s で回転 |
| LLH | WGS84 楕円体の緯度・経度・楕円体高 |
| NED | 局所の北・東・下 |
| BODY | 機体軸。+X が機軸（推力方向）。NED→BODY は方位角 → 仰角 → ロール角の順の回転 |

ECEF → LLH は Bowring の閉形式で、楕円体高は `h = p cosφ + z sinφ − a√(1 − e² sin²φ)` なので極でも成り立ちます。軌道要素の昇交点赤経だけは、打ち上げ時刻のグリニッジ平均恒星時（IAU 1982）を足して春分点基準にします。

## 運動方程式

状態量は ECI での `[質量 m, 位置 r, 速度 v]` の 7 成分です。

```
dm/dt = −ṁ
dr/dt = v
dv/dt = (C_body→ECI (F_thrust + F_aero)) / m + g(r)
```

### 重力

WGS84 / EGM96 の J2 項までの重力（正規化係数 C̄20 = −0.484165371736e-3）を ECI で計算します。地表より内側では地表の値で頭打ちにします。

### 推力

```
F_thrust = max(F_vac(t) − A_e p(h), 0)      A_e: ノズル出口面積
ṁ        = F_vac(t) / (Isp_vac(t) g0)
```

`F_vac` と `Isp_vac` は定数かテーブル（段の開始からの時刻）です。

燃焼は `burn_start_s` から「`burn_end_s`」「分離」「推進剤切れ」の最も早い時刻まで続きます。推進剤切れは、質量が `その段より上の質量 + 乾燥質量` に達する時刻を根探索で求めます（乾燥質量を指定しないときは、その段の質量すべてが推進剤）。

推力の向きは機軸です。推力トリム（neutrality）を使うと、重心まわりの推力モーメントが空力モーメントと釣り合うジンバル角に傾けます（旧C++版と同じ式。ピッチとヨーを別々に求め、合成角を補正します）。

### 空力

```
q = ½ ρ |v_air|²         v_air = v_ECEF − v_wind
F_aero,x = −CA(M) q S
F_aero,⊥ = −CN(M, γ) q S  （機軸と気流を含む面内、横流れと逆向き）
```

γ は機軸と気流のなす角（全迎角、0〜90°）です。空力係数と基準面積 S は段ごとです。CA は燃焼していないときだけ別の値（定数または Mach テーブル）にできます（ベース抗力の違い）。CN は Mach × 迎角の 2 次元表（`cn_table`）、または CNα(M) × γ [rad] です。ピッチとヨーの迎角が同時にあるときも、全迎角で CN を 1 回だけ引きます（CN(α) と CN(β) を足すと、非線形な CN では過大になるため）。気流が後ろから来るとき（姿勢を固定したまま再突入するときなど）は機体を前後対称とみなすので、空力は常に対気速度と逆向きで、エネルギーを加えません。軸力は横向きの気流をまたぐとき ±1° 程度でなめらかに符号を変えます。

燃焼後のモードによって、空力の扱いが変わります。

| モード（`flight_mode`） | 姿勢 | 空力 |
| --- | --- | --- |
| `powered`（燃焼中） | 姿勢プログラム | CA, CN |
| `attitude_program` | 姿勢プログラム | CA, CN |
| `aero_stable` | 気流に沿う | CA のみ |
| `ballistic` | 気流に沿う | 抗力加速度 q / β |

姿勢プログラムは方位角・仰角・ロール角を時刻で補間した航法座標系で、機体はそこから取り付け誤差（ヨー → ピッチ → ロール）とジャイロバイアスによるドリフト（`|b| t` だけ `b` 軸まわり）だけ回ります。

### 大気

`atmosphere.model` で選びます。

- `ussa1976`（既定）: 86 km まではジオポテンシャル高度 `H = r0 z / (r0 + z)`（r0 = 6356.766 km）で評価し、86〜1000 km は U.S. 標準大気 1976 の表値を対数補間します。
- `legacy`: 旧C++版と同じ。1976 年標準大気の 7 層を**幾何高度**で評価し、84.852 km より上は 186.95 K の等温層として外挿します（`convert` した旧形式の設定はこちら）。

幾何高度とジオポテンシャル高度の差は 30 km で約 140 m、80 km で約 1 km です。そのため `legacy` の密度は 30 km で約 2 %、80 km で十数 % 小さくなります。また、等温外挿は 150 km で表値の約 1/40 の密度です。

密度は季節変動（U.S. 標準大気の季節変動の高度分布）か高度ごとの偏差テーブルで `ρ (1 + 変動)` にします。風は北・東成分を高度で線形補間します。

### 発射台とランチャ

初速 0 で始めると、機体は地球に固定された直線レールに拘束されます。レールの向きは t = 0 の機軸です。回転座標系での相対加速度

```
a_rel = a − ω×(ω×r) − 2 ω×v_rel
```

のうちレール方向の成分だけを残し、離昇前は 0 未満を 0 にします（推力が重量に負けている間は保持）。離昇（動き出し）とレール端（`rail_length_m`）は根探索で求めます。レール長が 0 なら離昇で拘束を外します。

## 数値計算

### 積分器

- **RK4**（既定）: 固定刻み。各区間（イベント間・出力間）を刻み幅以下に等分します。
- **RK45**: Dormand–Prince 5(4)。FSAL を使い、成分ごとに `atol + rtol max(|y|, |y_new|)` で正規化した誤差の最大値が 1 以下なら採択します。刻み幅は 1e-6〜10 秒です。最小刻みでも許容誤差を満たせないときは採択して進め、その回数を警告します。

状態は固定長配列なので、ステップごとのメモリ確保はありません。派生量（高度、Mach、IIP など）は出力点でだけ計算します。

### 不連続点とイベント

着火・燃焼終了・分離・投棄物の切り離しは予定された不連続点です。積分器はその時刻でいったん止まり、区間の中では段や燃焼の状態を固定します（RK の中間段が区間端で次の状態を見ないように）。

状態で決まるイベントは、直前の出力点から積分し直して時刻を求めます。

| イベント | 求め方 |
| --- | --- |
| 着地（高度 0） | Illinois 法、高度 1 mm 以内 |
| 遠地点（対地鉛直速度 0） | Illinois 法 |
| マッハ 1（上昇方向） | Illinois 法 |
| 最大動圧 | 黄金分割探索 |
| 推進剤切れ | Illinois 法（質量） |
| 離昇・レール端 | 二分法・Illinois 法 |

イベントは `summary.json` と WASM の結果の `events`、CLI の表示に出ます。燃焼終了と分離のイベントには、その時点の軌道要素（点質量地球のケプラー要素）が付きます。

### 精度

刻み幅を変えても、サンプル機体（`examples/`）の最高高度（出力点での最大値）はほとんど変わりません（差は 0.1 m 程度）。

| ケース | RK4（出力間隔の半分） | RK4 0.1 s | RK4 0.01 s | RK45 |
| --- | --- | --- | --- | --- |
| sample_01 | 673688.801 m | 673688.722 m | 673688.726 m | 673688.737 m |
| MOMO | 100718.036 m | 100718.119 m | 100718.119 m | 100718.122 m |
| SS-520-4 | 1459020.864 m | 1459020.864 m | 1459020.945 m | 1459020.940 m |

大気圏外の慣性飛行では、J2 を含む力学的エネルギーと角運動量の極成分が 6000 秒で相対 1e-9 以内で保存されます（`tests/conservation.rs`）。

## 旧C++版との関係

`tests/cpp_reference.rs` は C++ 版（v0.52）の出力と比べる回帰テストです。旧形式の設定を `convert_legacy` で変換して飛ばし、単段、取り付け誤差・ジャイロバイアス・風テーブル・密度テーブル、CN/CP テーブルと推力トリムの 3 ケースで、高度 10 m、緯度経度 1e-4°、トリム角 0.005° 以内で一致します（実際の差は高度で 2〜5 m）。C++ 版のソースと比較スクリプト `tools/compare_cpp.py` は git タグ `cpp-v0.52` に残してあります。

C++ 版と結果が異なる、意図した違いは次のとおりです。

| 項目 | C++ 版 | Rust版 |
| --- | --- | --- |
| 定数 CN | 迎角によらず Y・Z 軸に −CN q S | CNα として迎角に比例 |
| CN の合成 | CN(α) と CN(β) を別々に足す | 全迎角で 1 回（純ピッチ・純ヨーでは同じ） |
| 段の質量 | その段より上の総質量 | その段単体の質量（全段の和が打ち上げ質量） |
| 推進剤切れ | なし（質量が負になり得る） | 乾燥質量で燃焼を終える |
| 発射台・ランチャ | なし（推力重量比 < 1 だと沈む） | 保持とレール拘束 |
| 有効推力 | 負になり得る | 0 で打ち切り |
| 燃焼後の出力 | 姿勢・推力・ジンバル角が燃焼終了時の値のまま | その時点の値 |
| 標準大気 | 幾何高度・等温外挿のみ | `ussa1976`（既定）と `legacy` |
